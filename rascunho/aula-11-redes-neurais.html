Parte I · Neurônio artificial

Dos atributos à ativação

Na Aula 10, usamos medições químicas para identificar a classe de um vinho. Vamos usar duas dessas medições para acompanhar o cálculo de um neurônio da camada oculta. As entradas são valores padronizados, e os pesos abaixo foram escolhidos para o exemplo.

O neurônio multiplica cada entrada x pelo peso correspondente w, soma os produtos e acrescenta um viés b. O viés desloca a soma e altera o ponto em que a unidade começa a ativar. Aplicamos então a função ReLU, que devolve zero quando a soma é zero ou negativa e a própria soma quando ela é positiva.

Soma ponderada z = w1x1 + w2x2 + b. Saída a = ReLU(z) = max(0, z).

Experimente com duas entradas

Varie as medições com os pesos 0,8 e −0,6 e o viés −0,5 fixos.

Soma ponderadaz = 0,8 × (2,0) − 0,6 × (1,0) − 0,5 = 0,5

Saída do neurônioa = ReLU(0,5) = 0,5

Mantenha o ácido málico em 1,0. Antes de mover o controle, calcule a saída que o neurônio produzirá se o valor do álcool passar para 1,0.

Conferir o cálculo

Com as duas entradas em 1,0, a soma é 0,8 − 0,6 − 0,5 = −0,3. A ReLU produz zero.

Parte II · Arquitetura

Como os neurônios formam uma rede

Em um perceptron multicamadas (MLP), cada neurônio de uma camada densa recebe as saídas da camada anterior. Na prática com Wine, cada neurônio oculto recebe as 13 medições, tem seus próprios pesos e viés e produz uma ativação. A camada de saída combina as oito ativações para gerar um escore por classe.

  1. 13EntradasMedições químicas padronizadas.→
  2. 8Neurônios ocultosSoma ponderada, viés e ReLU em cada neurônio.→
  3. 3SaídasUm escore para cada classe.

Na saída, a softmax converte os três escores em probabilidades que somam 1. O modelo prevê a classe de maior probabilidade. A regressão logística multiclasse calcula os escores diretamente dos atributos. A MLP calcula os escores a partir das ativações produzidas pela camada oculta.

Uma sequência de somas ponderadas com vieses ainda pode ser escrita como uma única transformação afim. Com a ReLU, cada neurônio pode contribuir em uma região das entradas e produzir zero em outra. Combinar essas regiões permite à MLP representar fronteiras de decisão não lineares.

Parte III · Treinamento

Como a rede ajusta os pesos

O treinamento começa com valores iniciais para os parâmetros. A rede calcula as probabilidades, compara a previsão com a classe observada e obtém uma perda. Na classificação multiclasse, a perda por amostra aumenta à medida que diminui a probabilidade atribuída à classe correta.

Probabilidade da classe 1, que é a corretaPerda da amostra
0,75−ln(0,75) ≈ 0,29
0,10−ln(0,10) ≈ 2,30
  1. Passagem para frente. Calcular as ativações, os escores e a perda para os exemplos de treino.
  2. Retropropagação. Calcular os gradientes da perda em relação aos pesos e vieses, da saída para as camadas anteriores.
  3. Otimização. Usar os gradientes para atualizar os parâmetros ao longo do treinamento.

Os pesos e vieses são parâmetros ajustados no treino. O número de neurônios ocultos é um hiperparâmetro definido antes do ajuste. Uma rede maior pode se ajustar melhor ao treino e piorar em dados novos. Comparamos o desempenho na validação para investigar esse efeito.

Na prática, a entropia cruzada compõe a função que a MLP minimiza no treino. Na validação, usamos o F1 macro, que calcula o F1 de cada classe e faz a média dando o mesmo peso a cada uma.

Parte IV · Prática guiada

Regressão logística e MLP no Wine

Execute os blocos em ordem, em três células de um notebook Python. O experimento usa as mesmas 178 amostras, a mesma divisão estratificada e as mesmas cinco partições de validação da Aula 10. Assim, os dois modelos são comparados nas mesmas condições.

1. Preparar os dados e reservar o teste

Os dados de desenvolvimento serão usados no treino e na validação cruzada. As 36 amostras de teste ficam reservadas até a escolha do modelo.

Python · Dados
from sklearn.datasets import load_wine
from sklearn.model_selection import train_test_split, StratifiedKFold

X, y = load_wine(return_X_y=True, as_frame=True)
X_dev, X_teste, y_dev, y_teste = train_test_split(
    X, y, test_size=0.20, stratify=y, random_state=42
)
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)

print(f"Desenvolvimento: {len(X_dev)} | Teste: {len(X_teste)}")

2. Comparar os modelos na validação

O pipeline ajusta a imputação e a padronização apenas no treino de cada partição. A tupla (8,) define uma camada oculta de oito neurônios. O otimizador L-BFGS usa os gradientes calculados pela retropropagação.

Python · Validação
from sklearn.impute import SimpleImputer
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_validate
from sklearn.neural_network import MLPClassifier
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

def criar_pipeline(estimador):
    return Pipeline([
        ("imputacao", SimpleImputer(strategy="median")),
        ("escala", StandardScaler()),
        ("modelo", estimador),
    ])

candidatos = {
    "Regressão logística": LogisticRegression(max_iter=2000),
    "MLP": MLPClassifier(
        hidden_layer_sizes=(8,), activation="relu", solver="lbfgs",
        max_iter=1000, random_state=42
    ),
}

f1_medios = {}
avaliacoes = {}
for nome, estimador in candidatos.items():
    avaliacao = cross_validate(
        criar_pipeline(estimador), X_dev, y_dev,
        cv=cv, scoring="f1_macro", return_estimator=True
    )
    avaliacoes[nome] = avaliacao
    f1 = avaliacao["test_score"]
    f1_medios[nome] = f1.mean()
    print(f"{nome}: F1 macro médio {f1.mean():.3f} | DP {f1.std():.3f}")

rede = avaliacoes["MLP"]["estimator"][0].named_steps["modelo"]
print("Dimensões das matrizes de pesos:", [w.shape for w in rede.coefs_])

Os resultados de referência são 0,980 para a regressão logística e 0,965 para a MLP no F1 macro médio. O DP indica a variação da métrica entre as partições. A rede treinada na primeira partição tem matrizes de pesos (13, 8) e (8, 3). Relacione esses valores com o diagrama das camadas. Os resultados podem variar com a versão da biblioteca.

Antes de executar o bloco seguinte, identifique qual modelo a regra do maior F1 macro médio seleciona. Use as médias e os desvios padrão para descrever o que observou nesta comparação.

3. Avaliar o modelo escolhido no teste

Ajuste novamente o modelo selecionado usando todos os dados de desenvolvimento. Use o teste para registrar seu desempenho final e localizar seus erros.

Python · Teste final
from sklearn.metrics import confusion_matrix, f1_score

selecionado = max(f1_medios, key=f1_medios.get)
pipeline_final = criar_pipeline(candidatos[selecionado])
pipeline_final.fit(X_dev, y_dev)
y_previsto = pipeline_final.predict(X_teste)

print("Modelo selecionado:", selecionado)
print(f"F1 macro no teste: {f1_score(y_teste, y_previsto, average='macro'):.3f}")
print("Matriz de confusão (linhas reais, colunas previstas):")
print(confusion_matrix(y_teste, y_previsto, labels=[0, 1, 2]))

Identifique os erros na matriz. Para cada célula fora da diagonal com contagem positiva, indique a classe real e a classe prevista.
